Монгол хэлэнд ураг төрлийн нэршил маш нарийн: **эцгийн тал (авга)** ба **эхийн тал (нагац)**, **насаар ах дүү**, **гэрлэлтээр холбогдсон хүмүүс** бүгд өөр өөр нэртэй. Доорх нь өнөөдөр хамгийн түгээмэл хэрэглэгддэг нэрс. Платформын **«Ураг төрөл»** хэрэгсэл эдгээр дүрмээр таны модноос автоматаар тооцоолдог.

## Ах дүү

| Хэн | Нэр |
|---|---|
| Насаар ахмад эрэгтэй | **Ах** |
| Насаар ахмад эмэгтэй | **Эгч** |
| Насаар бага | **Дүү** (эрэгтэй дүү, эмэгтэй дүү) |
| Аав нэг, ээж өөр | **Эцэг нэгт** ах / эгч / дүү |
| Ээж нэг, аав өөр | **Эх нэгт** ах / эгч / дүү |
| Хойд эцэг, эхийн хүүхэд | **Дагавар** ах / эгч / дүү |

## Эцгийн тал — авга

| Хэн | Нэр |
|---|---|
| Аавын ах, эрэгтэй дүү | **Авга ах** (ахмадыг нь их авга, залууг нь бага авга) |
| Аавын эгч, эмэгтэй дүү | **Авга эгч** |
| Авга ахын эхнэр | **Авга бэргэн** |
| Аавын аав, ээж | **Өвөө, эмээ** |

## Эхийн тал — нагац

| Хэн | Нэр |
|---|---|
| Ээжийн ах, эрэгтэй дүү | **Нагац ах** |
| Ээжийн эгч, эмэгтэй дүү | **Нагац эгч** |
| Нагац эгчийн нөхөр | **Нагац хүргэн ах** |
| Ээжийн аав, ээж | **Нагац өвөө, нагац эмээ** |

## Үеэл, ач, зээ

| Хэн | Нэр |
|---|---|
| Аавын ах дүүгийн хүүхэд | **Үеэл** |
| Ээжийн эгч дүүгийн хүүхэд | **Бүл** |
| Аавын эгч дүү / ээжийн ах дүүгийн хүүхэд | **Нага** |
| Үеэлийн хүүхэд, элэнц өвөө нэгт | **Хаяал** |
| Хүүгийн хүүхэд | **Ач** |
| Охины хүүхэд | **Зээ** |
| Ах, эрэгтэй дүүгийн хүүхэд | **Ач** |
| Эгч, эмэгтэй дүүгийн хүүхэд | **Зээ** |

## Гэрлэлтээр холбогдсон хүмүүс

| Хэн | Нэр |
|---|---|
| Хүүгийн эхнэр | **Бэр** |
| Охины нөхөр | **Хүргэн** |
| Ахын эхнэр | **Бэргэн** |
| Дүүгийн эхнэр | **Дүү бэр** |
| Эгчийн нөхөр | **Хүргэн ах** |
| Эхнэр / нөхрийн аав, ээж | **Хадам эцэг, хадам эх** |
| Эхнэр / нөхрийн ах эгч дүү | **Хадам ах, хадам эгч, хадам дүү** |
| Хүүхдүүд нь гэрлэсэн хоёр айлын эцэг, эх | **Худ, худгуй** |
| Эгч дүү хоёрын нөхрүүд | **Баз** |
| Хойд эцэг, хойд эх | **Хойд эцэг, хойд эх** |
| Эхнэр, нөхрийн өмнөх хүүхэд | **Дагавар хүү, охин** |

> Нэршил нутаг нутагт, тэр ч байтугай гэр бүлд ч ялгаатай байдаг. Ялангуяа *ач / зээ*, *бүл / нага*-г хэрэглэх нь нутгаас хамаарна. Танай гэрт хэрхэн дууддагийг ахмадуудаасаа асуугаарай.
